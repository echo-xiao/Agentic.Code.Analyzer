# How is a message rendered from raw text to React components in Rocket.Chat?

## Gemini Answer

The rendering of a message from raw text to React components in Rocket.Chat follows a pipeline involving several key steps and components:

**Flow:**

1.  **Raw Message Text:** The process begins with the raw message text, typically found in `message.msg`.
2.  **Parsing to AST:** The raw message text is then parsed into an Abstract Syntax Tree (AST). This is handled by the `parse()` function.
3.  **Rendering AST to React Components:** The generated AST nodes are then rendered into actual React components by the `<Markup>` component.

**Key Files:**

*   **`packages/message-parser/src/index.ts`**: This file contains the `parse()` function, responsible for converting the raw message text into an Abstract Syntax Tree (AST).
*   **`packages/gazzodown/src/Markup.tsx`**: This React component takes the AST generated by the message parser and renders it into a hierarchy of React components, effectively displaying the formatted message.
