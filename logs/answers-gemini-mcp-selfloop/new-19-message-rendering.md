# How is a message rendered from raw text to React components in Rocket.Chat?

intent: call-chain

## Gemini Answer

The rendering of a message from raw text to React components in Rocket.Chat follows a pipeline involving parsing the raw text into an Abstract Syntax Tree (AST) and then rendering these AST nodes as specific React components.

The flow is as follows:

1.  **Raw Text Input**: The process begins with the raw message text.
2.  **Parsing**: The raw text is processed by the `parse` function, located in `packages/message-parser/src/index.ts`. This function takes the input string and converts it into an Abstract Syntax Tree (AST), which is represented as a series of nodes or "tokens."
3.  **React Component Rendering**: The generated AST nodes (tokens) are then consumed by the `Markup` React component, found in `packages/gazzodown/src/Markup.tsx`. This component iterates through the array of tokens. For each token, it uses a `switch` statement to determine the token's `type` (e.g., `BIG_EMOJI`, `PARAGRAPH`, `HEADING`, `UNORDERED_LIST`, `ORDERED_LIST`, `TASKS`, `QUOTE`, `SPOILER_BLOCK`, `CODE`, `KATEX`, `LINE_BREAK`). Based on the type, it renders a corresponding React component, such as `BigEmojiBlock`, `ParagraphBlock`, `HeadingBlock`, `UnorderedListBlock`, `OrderedListBlock`, `TaskList`, `QuoteBlock`, `SpoilerBlock`, `CodeBlock`, `KatexBlock`, or a simple `<br />` for line breaks.

**Core Files:**

*   **`packages/message-parser/src/index.ts`**: Contains the `parse` function, responsible for converting raw message text into an Abstract Syntax Tree (AST).
*   **`packages/gazzodown/src/Markup.tsx`**: This React component takes the AST nodes (tokens) generated by the `parse` function and renders them as the appropriate React components for display.
