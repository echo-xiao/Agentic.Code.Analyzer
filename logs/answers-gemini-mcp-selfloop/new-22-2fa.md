# How does two-factor authentication (2FA) work in Rocket.Chat?

## Gemini Answer

**Entry Point:** `apps/meteor/app/2fa/server/twoFactorRequired.ts`

**Call Chain:**

1.  **`twoFactorRequired`** (apps/meteor/app/2fa/server/twoFactorRequired.ts): This acts as a middleware wrapper, enforcing 2FA for sensitive operations. It serves as the initial gatekeeper for any process requiring 2FA.

2.  **`checkCodeForUser`** (apps/meteor/app/2fa/server/code/index.ts): Triggered by `twoFactorRequired`, this central function orchestrates the 2FA validation process.
    *   It first retrieves user details necessary for the check using `getUserForCheck`.
    *   It then assesses if the user has a valid "remember me" token for 2FA through `isAuthorizedForToken`.
    *   `checkCodeForUser` identifies the enabled 2FA methods for the user via `getSecondFactorMethod` and `getAvailableMethodNames`.
    *   It proceeds to attempt verification using the configured 2FA methods in a specific order:
        *   **TOTPCheck (Authenticator App):** Validates codes generated by authenticator apps (e.g., Google Authenticator) against standard RFC 6238 time-based codes. The `ICodeCheck` interface (which `TOTPCheck` implements) specifies a `verify()` method for this.
        *   **EmailCheck (Email Code):** If TOTP is not enabled or fails, it verifies a code sent to the user's registered email address. This involves sending a temporary code via the Mailer service and validating it. `EmailCheck.ts` contains `getUserVerifiedEmails` and implements the `ICodeCheck` interface with its own `verify()` method.
        *   **PasswordCheckFallback:** As a final fallback, it may allow a password-based verification if configured.

3.  **`rememberAuthorization`** (apps/meteor/app/2fa/server/code/index.ts): Upon successful 2FA verification, this function is called to generate and store a temporary token, allowing the user to bypass 2FA for a configurable period, based on a browser fingerprint.

**Summary:**

Rocket.Chat's 2FA system starts with a `twoFactorRequired` middleware that directs to `checkCodeForUser`. This function verifies the user against configured 2FA methods (TOTP, Email, Password Fallback), leveraging specific `ICodeCheck` implementations for each. Successful verification can lead to the creation of a "remember me" token via `rememberAuthorization`, reducing friction for subsequent logins from trusted devices.
