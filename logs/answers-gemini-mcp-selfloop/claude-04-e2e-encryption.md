# How are the keys managed for end-to-end (E2E) encryption in Rocket.Chat?

## Gemini Answer

Rocket.Chat manages E2E encryption keys primarily client-side within the `apps/meteor/client/lib/e2ee/` directory.

Here's the key management process:

1.  **Key Pair Generation:**
    *   The `E2E` class in `apps/meteor/client/lib/e2ee/rocketchat.e2ee.ts` initiates the process with its `createAndLoadKeys()` method.
    *   This method calls a `generateKeyPair` function (e.g., in `packages/rocketchat-ui-sidenav/client/components/calls/shared.ts`) to create an RSA key pair for the user.
2.  **Private Key Encryption:**
    *   The generated RSA private key is immediately encrypted.
    *   This encryption involves two steps:
        1.  A derived key is generated from the user's password using **PBKDF2** (Password-Based Key Derivation Function 2).
        2.  The derived key is then used to encrypt the private key with **AES-GCM** (Advanced Encryption Standard - Galois/Counter Mode).
3.  **Per-Room Session Key Management:**
    *   For each encrypted room, an **AES session key** is generated by the `E2ERoom.createGroupKey()` method.
    *   This AES session key is then encrypted individually for each participant in the room using their respective **RSA public keys** via the `encryptGroupKeyForParticipant()` function.
4.  **Key Storage and Retrieval:**
    *   The `Keychain` component manages the storage of these encrypted keys.
    *   The `EncryptedKeyCodec` class, located in `apps/meteor/client/lib/e2ee/keychain.ts`, is crucial for this. It acts as a codec, with `encode` and `decode` methods, to convert `EncryptedKey` objects into a storable format (`IStoredKeyV2`) and vice-versa.

**Call Chain:**

*   `apps/meteor/client/lib/e2ee/rocketchat.e2ee.ts` (`E2E.createAndLoadKeys`)
    *   `packages/rocketchat-ui-sidenav/client/components/calls/shared.ts` (contains `generateKeyPair` which calls `generateKey` and `exportKey`)
*   `apps/meteor/client/lib/e2ee/keychain.ts` (`EncryptedKeyCodec` for storage management)

The server also plays a role by enforcing E2E-related settings like `E2E_Enable` and `E2E_Allow_Unencrypted_Messages`.
